About Me

Student developer. Privacy-first AI engineer.

I build browser-native AI applications, privacy-focused face recognition systems, premium e-commerce platforms, and single-file web experiences that run entirely client-side. I believe powerful tech should be lightweight, accessible, and respectful of user privacy.

Face descriptors > raw images. Everything stays in your browser.
  • 🎓 Student & Chairperson @ SoftwareLabs — Founder of Bevenu, a premium sustainable fashion e-commerce platform.
  • 💻 Specializing in TensorFlow.js, face-api.js, Cloudflare Workers & Vanilla JS — zero build steps.
  • 🎯 Privacy-first AI: blink detection, liveness checks, anti-spoofing, lightweight YOLO, browser-based NLP.
  • 🧩 Single-file HTML/CSS/JS deployments — inline CSS/JS, CDN libraries, instant deploy.
  • 🌐 Deploying via Cloudflare Pages, Workers, GitHub Pages, Netlify & Vercel — 1-click CI/CD.
  • 🚀 Currently building: BEVENU Clothings.
